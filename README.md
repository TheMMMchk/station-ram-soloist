## Установка
> [!NOTE]
> Для установки и запуска нужен curl. Убедитесь что он есть в PATH или разместите curl по пути `/opt/bin/curl`
1. Скачайте `install.sh` из релиза
2. Запустите его на Яндекс станции
3. Скрипт создаёт конфиг по пути `/data/opt/ramsoloist/config`.
4. Измените содержание файла `/data/opt/ramsoloist/config/apikey` на свой ключ 
## Запуск
После установки `install.sh` не запускает Soloist автоматически

Для запуска используйте один из способов:
- Вручную запустите `/data/opt/ramsoloist/start.sh`
- Перезагрузите колонку — Soloist запустится автоматически.

## Конфиг
Конфиг находится по пути `/data/opt/ramsoloist/config/config.env`
### Параметры конфига:
- `DEVICE_NAME`: содержит название отображающийся в клиенте Spotify при выборе колонки. По умолчанию `Yandex Station`
- `INITIAL_VOLUME`: громкость Spotify *(не самой колонки)* при запуске. По умолчанию `100`
- `RELEASE`: какой релиз для скачивания библиотек из моего репозитория использовать по тегу. По умолчанию `latest`

## Как устроено
> [!NOTE]
> *пока очень поверхностно т.к. репо в разработке и многое может имениться*
- `start.sh` скачивает через curl soloist в `/tmp/soloist/bin` также скачивает нужные библиотеки и запускает через них
- `stop.sh` останавливает все процессы soloist и удаляет папку `/tmp/soloist`
- `S99zzzramsoloist` запускает эти скрипты
